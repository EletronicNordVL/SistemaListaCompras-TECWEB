# 🏠 Módulo 02 - Página Principal (Index)

Este módulo abriga a **página de boas-vindas e portal de navegação** do sistema.

---

## 📄 Arquivos Presentes

- **`index.html`**: Landing page contendo a apresentação dos recursos do sistema, estilo embutido para cartões e botões de atalho.

---

## ⚙️ Funcionalidades e Destaques

1. **Apresentação de Recursos**:
   - Cartões ilustrativos destacando o **Cadastro de Produtos**, a **Lista de Compras** e a **Sincronização com o Servidor**.

2. **Navegação Intuitiva**:
   - Botões com chamadas para ação (`.btn-primary` e `.btn-success`) que direcionam rapidamente o usuário para o cadastro de produtos (`cadastro.html`) e para a lista de compras (`lista.html`).
   - Efeitos visuais de elevação ao passar o ponteiro do mouse (`:hover`).
